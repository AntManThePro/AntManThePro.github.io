⚙️ CHAPTER 1 — LINUX SETUP (THE PROMISED LAND)
1.
Open a terminal — Ctrl+Alt+T on most distros, or search "Terminal" in your app menu. On WSL: press Win+R, type wsl, Enter.
2.
Always run sudo apt update && sudo apt upgrade first. An unupdated system is a sin. Don't sin.
3.
Install the holy trinity first: sudo apt install curl git wget. Everything else builds on these three.
4.
For pip installs, use pip install X --break-system-packages on Ubuntu 23+. The system protects itself; override it.
5.
For brew installs, first get Homebrew: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
⚡ Pipe anything visual through | lolcat for instant rainbow mode. Everything is better in rainbow.
🪟 CHAPTER 2 — WINDOWS COMMAND ARTS
1.
CMD: Press Win+R, type cmd, Enter. For admin powers: right-click "Command Prompt" → "Run as Administrator". Admin = miracles.
2.
PowerShell: Press Win+X, then A for admin PowerShell. PS is a full scripting language — treat it like one.
3.
Install Windows Terminal from the Microsoft Store. It's free, it's beautiful, and it makes CMD look like a cave painting.
4.
Install winget (comes with Windows 11, or get it from the Store). Then: winget install X = instant apps.
5.
Install Scoop for dev tools: iwr -useb get.scoop.sh | iex in PowerShell. Then scoop install neofetch bat fd etc.
⚡ Any command marked HACKING requires CMD or PowerShell as Administrator. No admin = no miracles.
🌐 CHAPTER 3 — THE CURL GOSPEL
1.
curl is pre-installed on modern Windows 10/11 AND every Linux distro. No install needed — it is a gift.
2.
The basic formula: curl [URL]. Add -s to silence download progress. Add -L to follow redirects.
3.
For ascii.live animations: curl ascii.live/forrest — these are live server-side terminal art streams. Ctrl+C to escape.
4.
For wttr.in weather: curl wttr.in/Dallas or replace Dallas with any city. Add ?format=3 for compact one-line output.
5.
For cheat.sh: curl cheat.sh/COMMAND — replace COMMAND with anything: git, docker, vim, regex, python. Instant docs.
⚡ On Windows, curl works in CMD and PowerShell but Invoke-WebRequest (iwr) is the native PS equivalent if curl isn't found.
🔗 CHAPTER 4 — THE ART OF THE PIPE
1.
The pipe | is the most powerful character in any terminal. It chains commands: output of left → input of right. Chain without limit.
2.
Add | lolcat to ANY Linux command for rainbow output. echo "hello" | lolcat is the gateway drug.
3.
Add | cowsay to make a cow say any text. Chain them: fortune | cowsay | lolcat — dragon prophet in neon.
4.
| grep "keyword" filters output to only lines containing your word. systeminfo | grep Memory = instant RAM info.
5.
> file.txt saves output to a file. >> file.txt appends to it. 2>&1 captures errors too. Document everything.
⚡ Windows pipes work in both CMD and PowerShell but PS pipes pass OBJECTS not text — far more powerful for data manipulation.
⚡ CHAPTER 5 — WSL: THE BRIDGE BETWEEN WORLDS
1.
Install WSL2: open PowerShell as admin, run wsl --install. Restart. You now have Linux inside Windows. It's not a trick — it's real.
2.
Access your Windows files from WSL: cd /mnt/c/Users/YourName. Access WSL files from Windows: \\wsl$\Ubuntu\home\user
3.
Run Windows programs from inside WSL: explorer.exe . opens current folder in Windows Explorer. notepad.exe file.txt works too.
4.
Run Linux commands from Windows CMD/PS: wsl ls -la, wsl cat /etc/os-release. Prefix any Linux command with wsl.
5.
Free up RAM when done: wsl --shutdown from PowerShell. WSL2 can hog memory. Control it.
⚡ On your dual-boot Surface Pro: these CROSS-platform commands work on BOTH sides of the boot. Maximum efficiency.
