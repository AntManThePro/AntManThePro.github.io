# NEXUS EDITOR

Real-time HTML editor, ours, local-first. No account, no upload, no outside editor site.

- Open a file from your device, edit on the left, preview updates live on the right.
- AUTO preview (400 ms debounce) or RUN manually.
- Pack input: for multi-file apps like NEXUS Eye, load `cctv-pack.json` and the editor answers `cctv-pack.json` fetches locally in the preview.
- DOWNLOAD saves the edited file back to your device. Nothing is sent anywhere until you download or push.

Live: https://antmanthepro.github.io/editor/

**Custom Icon**: Enhanced neon `</>` with live pink/yellow pulse, NEXUS green/cyan on dark. Optimized for home screen / PWA. See `icon.svg` and `manifest.webmanifest`.
