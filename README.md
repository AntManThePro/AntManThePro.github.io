## NEXUS OSINT Vault

A locked shelf of public OSINT tools. No scraping people, no installs — just the good stuff in one place.

Live: https://antmanthepro.github.io/osint/

How to use:
1. Open the link and enter the operator key at the gate.
2. SHELF — pick a tool from the clone list, copy the green line, paste it in Terminal.
3. LINKS — opens public sites. BENCH — works on text you paste. CASE — drag board for linking entities.
4. Lock it when you're done. Everything stays in your browser.

Links: [live site](https://antmanthepro.github.io/osint/) · [NEXUS hub](https://nexus-world-hub.netlify.app/) · [repo](https://github.com/AntManThePro/antmanthepro.github.io)

## NEXUS Duct As-Built v2 — Field Kernel

Kitchen-exhaust as-builts, done on the roof instead of on paper. Describe the run, map the system, check it against NFPA 96, save the site packet.

Live: https://antmanthepro.github.io/duct/

How to use:
1. Open the link, start a site, name it.
2. Describe and measure the duct run — tap-to-measure on photos works with a calibration reference.
3. Run the NFPA 96 checks, then save and export the site packet.

Links: [live site](https://antmanthepro.github.io/duct/) · [NEXUS hub](https://nexus-world-hub.netlify.app/) · [repo](https://github.com/AntManThePro/antmanthepro.github.io)
